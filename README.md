# 조사 1팀 신규 조사원 홈페이지

정적 HTML/CSS로 만든 별도 GitHub Pages 홈페이지입니다. `index.html`은 연구청 기록 단말을 닮은 접속 화면이고 `profile.html`은 인물 기록입니다. 이름·나이·성별·실제 외형은 사용자가 아직 정하지 않았으므로 모두 미정으로 표시했습니다. 뒷모습 이미지는 확정된 인물 사진이 아니라 분위기 삽화입니다.

접속 화면과 인물 기록은 라이카 홈페이지의 문서형 레이아웃을 기준으로 맞추고, 이 인물에는 황갈색 강조색을 사용했습니다. 기존 서사와 능력 설명은 그대로 유지했습니다.

서사의 기준은 CYOA에서 고른 작은 마을과 외곽, 사냥꾼 경력, 함께 지내던 사람의 실종과 어긋난 기록, 사건 후의 메모, 공상 개화, 압력 변화 감지와 음향 분리, 조사 1팀 요원과의 현장 만남, 혼자 어려움을 떠안는 습관, 감각 과부하, 다층 방호 코트와 공상 오염 측정기입니다. 실종자의 신원과 행방, 조사 1팀 합류 이후의 사건은 확정하지 않았습니다.

`assets/forest-trail.jpg`와 `assets/investigator-back.jpg`는 내장 ImageGen으로 새로 만든 삽화입니다. 웹용 JPEG로 변환했고 생성 원본 PNG는 ImageGen 생성 폴더에 남아 있습니다. 프롬프트는 다음과 같습니다.

- 숲길: “비가 내린 작은 마을 외곽의 숲길, 중간에서 끊기는 발자국, 멀리 보이는 집 불빛, 나무 그루터기의 현장 수첩과 줄자. 인물 없이 조사와 실종을 암시하는 넓은 영화적 장면. 왼쪽 제목 여백, 숯색·푸른 회색·짙은 이끼색, 글자·로고 없음.”
- 인물 분위기: “안개 낀 숲 가장자리에서 마을을 바라보는 익명의 성인 조사원 뒷모습. 얼굴·나이·성별이 드러나지 않으며 어두운 방호 코트와 현장 가방을 착용. 무기·문장·글자 없음. 세로형 인물 기록 삽화.”

`assets/field-kit.jpg`와 `assets/erac-logo.png`는 기존 CYOA/Laika 프로젝트 자산을 재사용했습니다.

인적 사항과 실제 프로필 사진을 받은 뒤 `index.html`과 `profile.html`의 ‘미정’ 표기 및 분위기 삽화를 교체하면 됩니다.
